# Methodenkarten – Definitionen

Statische HTML-Seite mit 15 Methoden (plus Pitch) für Schülerinnen und Schüler: Kurzdefinition, Aufbau und Bewertungsraster (PDF) je Methode.

## Nutzung

Als GitHub Pages veröffentlichen: Repo-Einstellungen → Pages → Branch `main`, Ordner `/ (root)`. `index.html` ist die Startseite.

## Inhalt

- `index.html` – Übersicht + alle Methodenseiten
- `raster/` – Bewertungsraster als PDF, ein Download-Link pro Methode
- `Methodenkarten-Gesamt.zip` – alles in einem Download
